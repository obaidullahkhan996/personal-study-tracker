# Personal Study Tracker 

Personal Study Tracker is a simple Python project that helps me keep track of my daily study hours. I built this project to practice Python and learn how to create a useful application.

With this program, I can record the subjects I study, check my saved records, and calculate the total time I've spent studying.

## Features

- Add a study record with a subject name and study hours.
- View all saved study records.
- Calculate the total number of study hours.
- Save records in a JSON file so they are available when the program runs again.
- Handle invalid study-hour inputs.
- Use a simple menu to navigate through the program.

## Technologies Used

- Python
- JSON
- File Handling

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/obaidullahkhan996/personal-study-tracker.git
```

**2. Open the project folder**

```bash
cd personal-study-tracker
```

**3. Run the program**

```bash
python study_tracker.py
```

## How It Works

When the program starts, it loads previously saved study records from `study_records.json`, if the file exists.

You can then use the menu to add new records, view your study history, or calculate your total study hours. Whenever you add a record, the program saves the updated information to the JSON file.
